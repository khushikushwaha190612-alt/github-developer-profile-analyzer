GitHub Developer Profile Analyzer

About the Project

GitHub Developer Profile Analyzer is a C language project that analyzes publicly available GitHub profile and repository data using the GitHub REST API.

Features

- GitHub profile analysis
- Repository statistics
- Total stars and forks
- Popular repository identification
- Programming language analysis
- Developer score and activity insights
- Recommendations based on custom rules

Technologies Used

- C Programming
- GitHub REST API
- JSON
- curl
- GCC Compiler

How It Works

1. Enter a GitHub username.
2. The program fetches public profile information.
3. It retrieves repository data.
4. It calculates statistics and analyzes programming languages.
5. It displays a final analysis report.

Limitations

The score and recommendations are based on custom rules and are not official GitHub ratings. The program requires a working network connection and suitable C compiler setup.

Future Scope

- Web-based user interface
- Improved JSON parsing
- More detailed analytics
- Exportable reports
